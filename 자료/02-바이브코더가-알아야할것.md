# 바이브 코더가 알아야 할 것

> 출처: https://www.max5.ai/series/vibe-coding/part-1/03-what-vibe-coders-need

---

## 핵심 메시지

"코드 문법은 몰라도 되지만 개념은 알아야 한다"

"코딩 안 배워도 된다면서 뭔가는 알아야 한다니" — 이 혼동을 해소하는 것이 이 글의 목적입니다.

## 전통적 코딩 vs 바이브 코딩 학습

**전통적 코딩 학습**: "for문을 어떻게 쓰는지", "if문 다음에 뭐가 와야 하는지" 같은 문법 세부사항에 집중

**바이브 코딩**: "이 데이터를 하나씩 처리해야 해"(의도)와 같은 개념 이해에 우선순위

## 개념이 필요한 두 가지 이유

1. **명확한 지시**: 기술 개념을 이해하면 "알아서 해줘"라는 막연한 복권이 아니라 구체적인 주문서가 됩니다.

2. **AI 결과 판단**: 프로그램 종류, 프론트엔드/백엔드, 데이터베이스, API, 폴더 구조, 데이터 흐름 같은 개념을 알아야 AI가 생성한 결과물을 평가할 수 있습니다.

## 코드 보기 vs 짜기의 차이

**짜는 것(몰라도 됨)**: `function`, `const`, `Date.now()` 같은 문법

**보는 것(알아야 함)**: "할 일을 추가하는 기능이구나", "새 할 일에 id, 텍스트, 완료 여부가 들어가는구나" 같은 기능 이해

## 핵심 정리

- 전통 코딩은 문법부터, 바이브 코딩은 개념부터 시작
- AI가 코드를 처리하는 동안 여러분은 "뭘 만들지"와 "이게 맞는지"를 판단
- 프로그램 종류 → 구조 → 설계 개념 → 도구 → 실전 순서로 배움

**결론**: "뭘 만들지 알고, 그걸 AI한테 전달할 줄 아는 것"이 바이브 코딩입니다.
