# 목표 수준: 유능한 상사 되기

> 출처: https://www.max5.ai/series/vibe-coding/part-1/04-be-a-good-boss

---

## 핵심 개념

**기술적 지시가 가능한 매니저의 특징:**
- AI에게 여러 선택지를 물어볼 수 있음
- 선택지를 듣고 자신의 상황에 맞게 판단
- 판단한 방향으로 구체적으로 지시
- AI 결과물이 맞는지 확인 및 검증
- 코드를 직접 타이핑하지 않고, 버그를 직접 수정하지 않음

## 성장 단계

5단계 성장 경로:
1. **기능 요청 수준** (시작점)
2. **명세 제공 수준**
3. **구조 이해 수준**
4. **설계 대화 수준** (이 시리즈의 목표)
5. **성능/보안/확장성까지 고려하는 고도화 단계**

## 실제 예시

상품 검색/필터링 기능을 예로 들어, 막연한 지시가 어떻게 실패하고 기술적 대화가 어떻게 성공하는지 보여줍니다.

할일 관리 웹앱 사례에서도 "아키텍처 추천해봐" → 판단 → "이렇게 해줘"의 양방향 대화 흐름을 제시합니다.

AI에게 "만들어줘"라는 막연한 지시보다는 **기술적이고 구체적인 지시**가 중요합니다.
