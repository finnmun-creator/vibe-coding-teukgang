# 슬랙 봇 만들기

> 출처: https://www.max5.ai/series/vibe-coding/part-6/27-slack-bot

---

진정한 자동화는 "내가 신경 쓰지 않아도 내 눈앞에 배달되는 것".

## 학습 목표

- 슬랙으로 메시지를 보내는 비밀 주소(Webhook URL) 생성
- 코드로 메시지를 쏘는 POST 요청 방법
- AI에게 "이 메시지 슬랙으로 보내줘"라고 지시하기

---

## 1. 웹훅(Webhook): 디지털 초인종

슬랙에게 특정 URL로 편지를 보내면 지정된 채팅방에 표시됩니다.

URL 주소 하나만으로 메시지를 배달할 수 있지만, 이 주소는 비밀번호처럼 소중하게 다뤄야 합니다.

---

## 2. 슬랙 앱 만들고 주소 받기

1. [Slack API 사이트](https://api.slack.com/apps) 접속
2. **Create New App** → **From scratch**
3. 앱 이름(예: Morning News Bot) 지정 및 워크스페이스 선택
4. **Incoming Webhooks** 메뉴 클릭
5. **Activate Incoming Webhooks** 스위치 활성화
6. **Add New Webhook to Workspace** → 채널 선택

완성되면 `https://hooks.slack.com/services/T000.../B000.../XXXX...` 주소가 생성됩니다.

---

## 3. 실전: 메시지 쏘기

### 설치

```bash
npm install axios dotenv
```

### 코드

```javascript
const axios = require('axios');
require('dotenv').config();

async function sendToSlack(message) {
  const url = process.env.SLACK_WEBHOOK_URL;

  try {
    await axios.post(url, { text: message });
    console.log('슬랙 전송 완료!');
  } catch (error) {
    console.error('배달 실패:', error);
  }
}
```

### 환경변수 설정 (.env)

```
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T000...
```

### 실행

```bash
node index.js
```

## 핵심 정리

✅ **웹훅 URL**: 비밀번호 없이 사용할 수 있는 개인 우체통 주소
✅ **슬랙 앱**: Incoming Webhook 기능으로 주소 획득
✅ **환경변수(.env)**: 비밀 주소를 코드에서 분리하여 보관

## 셀프 체크

- 슬랙 봇 생성에 필수 기능 이름은? → Incoming Webhook
- 웹훅 주소 유출 시 위험은? → 아무나 내 채널에 메시지 가능
- 메시지 전송 시 HTTP 요청 방식은? → POST
