## npm과 package.json

개발 시 가장 답답한 순간: "내 컴퓨터에서만 작동 안 함"

NPM(Node Package Manager)이 이를 해결합니다. package.json이라는 레시피 파일만 있으면 누구나 동일한 환경을 구성할 수 있습니다.

## 학습 목표

- npm install의 정확한 역할 이해
- package.json을 레시피로 인식
- .env 파일로 민감한 정보 관리

---

## 1단계: 레시피 확인 (package.json)

```json
{
  "name": "vibe-project",
  "dependencies": {
    "react": "^18.2.0",
    "supabase-js": "^2.0.0"
  }
}
```

"프로젝트에 필요한 라이브러리 목록"입니다.

## 2단계: 장보기 (npm install)

```bash
npm install
```

실행 후 node_modules 폴더가 생성되며 모든 의존성이 설치됩니다.

**꿀팁**: node_modules는 용량이 크므로 Git에 업로드하지 않습니다(.gitignore에 등록).

## 3단계: 비밀 정보 숨기기 (.env)

API 키와 비밀번호는 코드에 직접 입력하면 안 됩니다.

1. 프로젝트 최상위에 `.env` 파일 생성
2. 민감 정보 추가:
```
API_KEY=abcdefg12345
DB_PASSWORD=secret1234
```

3. 코드에서 사용:
```javascript
const apiKey = process.env.API_KEY;
```

**주의**: .env 파일도 .gitignore에 추가!

---

## 정리: 필수 4가지 도구

1. **Terminal**: 컴퓨터와 통신
2. **VS Code**: 코드 편집
3. **Git**: 버전 관리
4. **NPM**: 의존성 관리

## 셀프 체크

- package.json의 라이브러리 한 번에 설치 → `npm install`
- 비밀 정보 저장 파일 → `.env`
- node_modules를 Git에 안 올리는 이유 → 용량 크고 재설치 가능
