## 핵심 개념

**원석(Raw Data) vs 보석(정보)**

인터넷상의 데이터는 대부분 정제되지 않은 원석입니다. 이 거친 원석에서 보석만 캐내야 해요.

개발자들은 이 작업을 **파싱(Parsing)**이라 부르며, 생선 가시를 발라내고 살코기만 남기는 작업에 비유됩니다.

## 학습 목표

- RSS의 정의와 크롤링 대비 장점 이해
- Node.js 환경에서 데이터 수집 코드 실행
- 불필요한 정보를 제거하고 필요한 정보만 추출

---

## 데이터 수집 방법 비교

### 크롤링 (Crawling) - "도둑" 방식
- 장점: 화면에 보이는 모든 데이터 수집 가능
- 단점: 사이트 구조 변경 시 오류, 차단 위험

### RSS - "전단지" 방식
- 장점: 구조 일정(XML 표준), 합법적이고 안전
- 단점: RSS 제공 사이트만 가능 (구글 뉴스는 지원)

## 실습 프로젝트

### 1단계: 프로젝트 세팅

```bash
mkdir my-news-bot
cd my-news-bot
npm init -y
npm install rss-parser
```

### 2단계: AI에게 코드 요청

"Node.js로 rss-parser를 사용해 구글 뉴스 RSS('인공지능' 검색)를 읽고, 최신 3개 기사의 제목과 링크를 출력해줘."

### 3단계: 코드 예시

```javascript
const Parser = require('rss-parser');
const parser = new Parser();

(async () => {
  const feed = await parser.parseURL(
    'https://news.google.com/rss/search?q=인공지능&hl=ko&gl=KR&ceid=KR:ko'
  );

  console.log(`=== '${feed.title}' 최신 뉴스 ===`);

  feed.items.slice(0, 3).forEach(item => {
    console.log(`[제목] ${item.title}`);
    console.log(`[링크] ${item.link}`);
    console.log('-------------------');
  });
})();
```

### 실행

```bash
node index.js
```

## 핵심 정리

✅ **크롤링 vs RSS**: RSS가 더 안전하고 편리
✅ **파싱**: 복잡한 데이터에서 필요한 속성만 추출
✅ **Node.js**: 브라우저 없이 JavaScript 실행
