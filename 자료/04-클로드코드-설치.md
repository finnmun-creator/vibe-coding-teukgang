# Claude Code 설치하기

> 출처: https://www.max5.ai/series/vibe-coding/part-2/05-install-claude-code

---

## 웹사이트 채팅 vs Claude Code

**웹사이트 채팅**: "말만" 할 수 있음. 코드를 작성해주지만 복사, 붙여넣기, 저장은 사람이 직접 해야 함.

**Claude Code**: "손발이 달린" AI. 파일을 직접 열어서 수정하고, 폴더를 만들며, 프로젝트를 설정함.

## 핵심 학습 목표

- Claude Code를 설치할 수 있다
- 터미널에 대한 두려움이 사라진다
- 터미널에서 claude 명령어를 실행할 수 있다

---

## 터미널의 본질

터미널은 **카카오톡**과 같습니다:

- **카카오톡**: 사람 ↔ 사람 대화창
- **터미널**: 사람 ↔ 컴퓨터 대화창

마우스 방식(GUI)과 터미널 방식(CLI)의 차이:

```
마우스 방식: 폴더 우클릭 → '새 폴더' 클릭 → 이름 입력
터미널 방식: mkdir my-folder (엔터)
```

---

## 설치 3단계

### 1단계: 터미널 열기

- **Mac**: Command + Space → `Terminal` 검색 → 엔터
- **Windows**: 윈도우 키 → `PowerShell` 검색 → 엔터

### 2단계: 설치 명령어 입력

```bash
npm install -g @anthropic-ai/claude-code
```

**주의**: `npm: command not found` 오류 시 Node.js LTS 버전 설치 필요.

### 3단계: 로그인

```bash
claude
```

브라우저가 열리면 Claude 계정으로 로그인 승인.

---

## 첫 업무 지시

터미널의 `>>` 표시에서 명령을 입력:

```
나: "현재 폴더에 있는 파일 목록 좀 보여줘."
Claude: "네, 현재 폴더에는..." (ls 명령어를 자동 실행)
```

명령어를 몰라도 AI가 알아서 처리합니다.

## 핵심 요약

1. 웹사이트 Claude = "말만 하는" 조언자
2. Claude Code = "손발이 달린" 실무자
3. 터미널 = 컴퓨터(AI)와 대화하는 채팅창

## 셀프체크

- 웹사이트 Claude와 Claude Code의 결정적 차이는? → 직접 파일 수정 가능 여부
- 터미널은 무엇과 빗대어 설명할 수 있나? → 컴퓨터와의 카카오톡 대화창
- 설치 확인 명령어는? → `claude --version`
